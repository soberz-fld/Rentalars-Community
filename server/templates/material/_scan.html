{% load i18n rentalars %} {% comment %} UIX-006, MAT-027 (scanning in the browser; PCK-010, PCK-011): the button that opens the scan dialog of static/js/scan.js. The dialog reads QR and bar codes with the camera where the browser can (BarcodeDetector; the page must be served over HTTPS), and always has a field for typing a code or for a hand scanner. Parameters: scan_mode "submit" (default): the code goes into the field scan_input and its form is sent; "plan": the code is resolved (material:scan_resolve) and its product added with scan_post. scan_input CSS selector of the field (mode submit). scan_post address that adds the product (mode plan). scan_continuous keep the dialog open for the next code. scan_label text of the button, default "Scan". Without scripts the button does nothing; the field next to it works as before. {% endcomment %}
