{% translate "How to switch it on" %}

{% translate "On the server, as root:" %}

sudo rentalars encryption enable

  1. {% translate "It writes a backup of the present state, which is never deleted automatically." %}
  2. {% translate "It stops Rentalars for a short time, gives MariaDB a key and restarts the database. MariaDB then encrypts every table." %}
  3. {% translate "It compares every table with the state from before. Only if not one value differs does Rentalars start again." %}
  4. {% translate "It encrypts the existing backups and every future one." %}
  5. {% translate "At the end it shows the recovery key. Write it down and keep it apart from the server: without it, encrypted backups cannot be opened – by nobody." %}

{% translate "With a database on another server the command encrypts the backups; whether the files of the database are encrypted is decided by that server. The state on the server:" %} sudo rentalars encryption status

{% endif %}

{% translate "Why there is no button for it" %}

{% translate "Switching encryption on changes the settings of MariaDB, restarts the database and stores a key that only root may read. Rentalars itself runs without these rights on purpose: even someone who took over an administrator account could then neither change the database server nor read the key." %}
