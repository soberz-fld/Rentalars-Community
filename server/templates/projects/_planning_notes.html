{% load i18n rentalars %} {% comment %} Hints that speak about all lines of the project. To know how many pieces are missing, the availability of every line must be calculated – the expensive part of the planning. After a change of one line the answer therefore comes without these hints (NFA-013), and this block fetches its content anew when it hears "planningChanged", which every such answer announces in its HX-Trigger header. If a second change is announced while the hints for the first are still being fetched, htmx queues one more fetch for when that one is done – but only for an element that is still in the page then. The block therefore stays and only its content is exchanged: hx-select takes the content out of the answer, which is this same template. A block that replaced itself would lose the queued fetch, and the hints would show the state between the two changes. The forms among the hints answer with the whole planning. They must not inherit hx-select, target and swap of this block – a form that did replaced the planning with the hints alone (PRJ-072) – hence hx-disinherit. {% endcomment %}
