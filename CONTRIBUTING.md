# Contributing

Contributions are welcome: bug reports, fixes, translations, documentation.

This repository holds several components, each in a folder of its own (at the moment [`server/`](server/)). The rules for
code, tests, commits and the checks that must pass are in [server/CONTRIBUTING.md](server/CONTRIBUTING.md); they apply to
the server and are the starting point for the other components. Run the checks of the component you changed before you open
a pull request – for the server, `server/scripts/check.sh`.

Open an issue before you start on a large change, so that the direction can be agreed first.

Beiträge sind willkommen: Fehlermeldungen, Korrekturen, Übersetzungen, Dokumentation. Die Regeln stehen in
[server/CONTRIBUTING.md](server/CONTRIBUTING.md).
